# Bean Theory

Static homepage for Bean Theory, a coffee brand. The page is HTML and CSS: a header, promotional sections, and a footer with company links and contact details.

## What’s on the page

- Header with the Bean Theory name, plus Menu, Rewards, and Gift Cards
- Find a store, Sign in, and Join now
- Store announcement
- Promotions for the summer prize game, rewards, food donation, iced drinks, pickup, delivery, and the college achievement plan
- Footer sections for About Us, Careers, Social Impact, business partners, and ordering
- Contact column for phone, email, and street address
- Social links, privacy policy, terms of use, and the copyright line

## Project files

- `index.html` — page content
- `packages/css/style.css` — header and base styles
- `packages/css/main.css` — main sections and footer

## View the site

Open `index.html` in a browser. There is no build step.
